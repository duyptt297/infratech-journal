## 🌟 1. Giới Thiệu (Overview)

**INFRA-TECH JOURNAL** là website tạp chí khoa học kỹ thuật chuyên sâu về các loại **vật tư, thiết bị và linh kiện công nghiệp** trong các nhà xưởng, khu chế xuất và tòa nhà cao tầng:
- **Cơ sở hạ tầng & Kết cấu (Civil & Infrastructure)**: Sàn tự san phẳng Epoxy chịu tải 15 tấn, panel PIR cách nhiệt chống cháy, kết cấu thép.
- **Cơ điện & HVAC (Mechanical & HVAC)**: Chiller ly tâm giải nhiệt nước, ống gió chống cháy chuẩn EI, van cân bằng áp tự động (PICV).
- **Điện động lực & Phân phối (Electrical & Power Systems)**: Thanh dẫn Busway Compact Sandwich 800A - 6300A, cáp điện chống cháy 950°C (Cu/Mica/XLPE/LSZH), máy biến áp khô đúc nhựa Cast Resin.
- **Đường ống công nghệ & Van (Process Piping & Valves)**: Ống thép đúc liền mạch ASTM A106 Gr.B SCH40/80, van cổng mặt bích WCB/CF8M, bẫy hơi đồng tiền.
- **PCCC & Cứu nạn (Fire Protection & Life Safety)**: Đầu phun Sprinkler tự động phân biệt màu bầu thủy tinh (Đỏ 68°C, Vàng 79°C, Xanh lục 93°C), hệ chữa cháy khí sạch FM-200.
- **Mạng công nghiệp & Tự động hóa (Industrial Network & Automation)**: Cáp mạng giáp kép Cat.7 S/FTP chống nhiễu biến tần, switch công nghiệp DIN-Rail.

## 🚀 2. Tính Năng Đột Phá Cho Thế Hệ Mới (Gen Z UX)

1. **Song Ngữ Tức Thì (1-Click Instant Bilingual Engine)**:
   - Chuyển đổi mượt mà giữa Tiếng Việt và English cho toàn bộ giao diện, thông số kỹ thuật, bài viết và câu hỏi trắc nghiệm.
2. **Phòng Thí Nghiệm 3D Tương Tác (Interactive 3D Lab)**:
   - Tích hợp công nghệ WebGL Three.js với 4 mô hình kỹ thuật chi tiết:
     - *Van Cổng Mặt Bích (Gate Valve)*: Khám phá trục ty ren thang Acme, đĩa chêm dẻo và mặt bích ASME B16.5.
     - *Cáp Chống Cháy 5 Tầng (Fire Cable)*: Bóc tách từng lớp từ ruột đồng, băng Mica 950°C, vỏ LSZH không khói.
     - *Đầu Phun Sprinkler PCCC*: Bóng thủy tinh nhạy nhiệt 68°C, khung đồng thau và đĩa định hướng tán nước.
     - *Thanh Dẫn Busway Sandwich*: Thanh dẫn đồng ETP 99.9%, vỏ nhôm tản nhiệt và bu-lông lực tự gãy chốt.
   - Chế độ **Bóc Tách Mặt Cắt (Exploded View)** và điểm nóng kỹ thuật (Engineering Hotspots).
3. **Đấu Trường So Sánh Đối Đầu (Side-by-Side Comparator)**:
   - So sánh trực tiếp 2 vật tư kỹ thuật với biểu đồ Radar đa chiều (Chịu nhiệt, Cơ học, Chi phí Capex, Dễ bảo trì, Tốc độ thi công, Độ tin cậy) kèm kết luận khuyến nghị kỹ thuật.
4. **Ma Trận Ra Quyết Định Kỹ Thuật (Decision Matrix)**:
   - Lọc theo điều kiện khắc nghiệt (Hóa chất ăn mòn, nhiệt độ cao, an toàn sinh mạng PCCC, phòng sạch GMP) để nhận danh sách vật tư tối ưu và cảnh báo tử huyệt cần tránh.
5. **Bộ Công Cụ Tính Toán Nhanh Cho Kỹ Sư (Engineering Calculators)**:
   - Tính lưu lượng đầu phun Sprinkler theo tiêu chuẩn NFPA 13 ($Q = K \times \sqrt{P}$).
   - Tính áp suất nổ và áp suất làm việc ống thép đúc theo công thức Barlow ($P = \frac{2 S t}{D}$).
   - Tính độ sụt áp tuyến cáp điện theo tiêu chuẩn quốc tế IEC 60364-5-52.
6. **Thử Thách Đấu Trí Kỹ Sư (Gamified Quiz Mode)**:
   - Ngân hàng câu hỏi trắc nghiệm thực tế công trường, tính điểm streak, hiệu ứng âm thanh và phong tặng huy hiệu Kỹ Sư Trưởng.
7. **Sơ Đồ Vector Chuẩn Xác (Precision SVG Cutaway Blueprints)**:
   - Toàn bộ sơ đồ mặt cắt vẽ dưới dạng vector SVG hiển thị sắc nét trên màn hình Retina 4K.

## 🛠️ 4. Cách Cập Nhật & Mở Rộng Nội Dung (How to Extend)

### Thêm một vật tư mới:
Mở tệp `js/data/materials.js` và thêm một đối tượng theo cấu trúc chuẩn:
```javascript
{
  id: "ten-vat-tu-moi",
  category: "mep-elec", // hoặc infra, mep-hvac, mep-plumb, pccc, net-auto
  has3DModel: false,
  badge: "SAFETY CERTIFIED",
  name: { vi: "Tên Tiếng Việt", en: "English Name" },
  tagline: { vi: "Mô tả ngắn gọn", en: "Short summary" },
  tags: ["IEC 60000", "Tag2"],
  image: "assets/images/so-do.svg",
  overview: { vi: "...", en: "..." },
  workingPrinciple: { vi: "...", en: "..." },
  specifications: [
    { labelVi: "Điện áp", labelEn: "Voltage", valueVi: "1000V", valueEn: "1000V", standard: "IEC" }
  ],
  pros: [...],
  cons: [...],
  standards: [...],
  failureCases: [...]
}
```

## 🌐 5. Hướng Dẫn Đưa Lên GitHub Của Bạn (Deploy to GitHub Pages)

Bạn có thể đưa toàn bộ website này lên tài khoản GitHub của bạn chỉ với vài bước đơn giản:

### Bước 1: Tạo một Repository mới trên GitHub
1. Đăng nhập vào [GitHub](https://github.com).
2. Nhấn nút **New repository** (hoặc dấu `+` ở góc trên bên phải).
3. Đặt tên repository, ví dụ: `infratech-journal` hoặc `tap-chi-csht`.
4. Chọn chế độ **Public** (để dùng GitHub Pages miễn phí).
5. Nhấn **Create repository** (không cần tick chọn README vì đã có sẵn).

### Bước 2: Đẩy mã nguồn từ máy tính lên GitHub
Mở phần mềm Git Bash, Command Prompt hoặc PowerShell tại thư mục dự án `e:\Tạp chí CSHT` và chạy các lệnh sau:

```bash
# 1. Khởi tạo kho git cục bộ
git init

# 2. Thêm tất cả các tệp vào git
git add .

# 3. Tạo commit đầu tiên
git commit -m "feat: Initial release of INFRA-TECH JOURNAL website"

# 4. Đổi tên nhánh chính thành main
git branch -M main

# 5. Liên kết với kho GitHub của bạn (thay username và repo-name bằng của bạn)
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>.git

# 6. Đẩy mã nguồn lên GitHub
git push -u origin main
```

### Bước 3: Kích hoạt GitHub Pages
1. Vào repository trên GitHub -> Chọn tab **Settings** (Cài đặt).
2. Ở thanh menu bên trái, chọn mục **Pages**.
3. Tại phần **Build and deployment**:
   - Mục **Source**: Chọn **GitHub Actions** (Quy trình tự động đã cấu hình sẵn trong `.github/workflows/deploy.yml`).
   *Hoặc* nếu muốn nhanh nhất không qua Actions: chọn **Deploy from a branch** -> chọn nhánh `main` và thư mục `/(root)` rồi nhấn **Save**.
4. Chờ khoảng 1-2 phút, GitHub sẽ hiển thị đường link trang web của bạn:
   👉 `https://<YOUR_GITHUB_USERNAME>.github.io/<YOUR_REPO_NAME>/`
